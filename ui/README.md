# CAgent 聊天前端

侧栏管理模块：

- 模型：新增、编辑、启停，配置上下文限制与思考参数。
- API Key：查看元信息、新增、修改权重和状态、删除、升级加密版本。
- Agent：创建主 Agent、分组与子 Agent，分页浏览层级，编辑和删除。
- Agent 的描述和系统提示词支持 Markdown 源码、预览和实时分栏模式，并提供格式工具栏。保存的是原始 Markdown 文本。预览支持标题、粗体、斜体、删除线、列表、引用、代码块与 HTTP(S)/邮件链接；原始 HTML 作为文本展示。目前不支持表格和嵌套列表等完整 GFM 扩展。
- 工具：新增 Local / A2A / MCP / Skill，筛选与分页，编辑关联 Agent 和服务地址，上线/下线。
- 加密密钥：生成新的后端 KMS 版本，操作前展示确认。

管理模块沿用聊天的认证 Cookie。后端未提供模型与工具删除接口，因此页面不提供这些操作。模型详情仅返回 API Key 元信息，编辑模型时未返回字段留空即不修改。生成 KMS 版本会写入后端 `.env`，前端不接收密钥明文。

原生 JavaScript + CSS，无第三方依赖，要求 Node.js 20+。

先按根目录 README 配置并启动后端（MongoDB、模型、主 Agent 及模型 API Key 都需可用），然后：

```powershell
cd ui
npm start
```

浏览器打开 http://127.0.0.1:5173 。服务仅监听本机。

监听端口从 `ui/config.json` 读取，修改 `port` 后重启服务即可：

```json
{
  "port": 3000
}
```

此时访问 http://127.0.0.1:3000 。端口必须是 1 到 65535 之间的整数；配置缺失或无效时会提示错误并退出。配置路径始终相对于 `server.mjs`，不受启动目录影响。`PORT` 环境变量不再用于设置端口。

默认将 `/cagent/v1/*` 代理到 `http://127.0.0.1:8080`，支持 Cookie 和 SSE 流式转发。修改后端地址：

```powershell
$env:CAGENT_API_URL = 'http://127.0.0.1:8080'
npm start
```

首次打开，在「连接与认证」中输入后端 `CAGENT_SERVER_HEADER` 对应的 Cookie 名称和业务系统签发的 JWT（包含后端 Auth 所需 ID、Name 等 claims，使用匹配的服务端密钥签名）。本项目没有登录或签发 JWT 的接口；前端不会生成令牌，也不需要签名密钥。令牌保存在当前浏览器会话 Cookie 中，关闭浏览器后按浏览器会话策略清除。此入口用于本地开发，生产环境应由业务登录系统设置 HttpOnly Cookie。

支持新建/删除会话、会话和消息分页、SSE 内容与思考过程、标题更新、断线后按 seq 重连、人工补充输入。切换会话仅断开订阅，不会停止后端任务。输出使用纯文本安全渲染，保留代码和换行。

重新进入会话时，先通过 GET /cagent/v1/session/:id 查询当前状态：运行中优先读取 SSE，不叠加历史消息；已结束只读取历史消息，不建立 SSE 连接。SSE 的 end 事件会触发状态核对，运行期间每 3 秒补充核对一次，防止旧 end 事件误判或结束事件丢失。确认结束后关闭 SSE 并用完整历史替换流式视图。同一连接中断使用 seq 续传。运行时只能展示缓冲区仍保留的输出，结束后可分页查看完整历史。前后端需要同时更新并重启。
